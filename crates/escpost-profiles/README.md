# escpost-profiles

`escpost-profiles` provides the printer-profile model and embedded profile
catalog used by [ESCPost](https://github.com/receiptful/escpost). Applications
can resolve profiles for rendering and inspect their geometry, capabilities,
defaults, and calibrated behavior.

The crate also exposes tooling for reading, writing, compiling, and
synthesizing canonical profiles. See the [repository documentation](https://github.com/receiptful/escpost/blob/main/docs/PROFILE_SCHEMA.md)
for the profile schema and authoring workflow.
