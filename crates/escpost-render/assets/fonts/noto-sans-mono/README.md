# Noto Sans Mono

`NotoSansMono-Regular.ttf` is the deterministic default glyph source used by
ESCPost. It is embedded in the Rust library; rendering never searches the
host system for fonts.

- Family: Noto Sans Mono
- Style: Regular
- Font version: 2.006
- SHA-256:
  `6b692c4b6d15ccf59f1c1fe8d11cb8a92f51960f3e9f1f523781755a3af7e29f`
- Upstream: <https://github.com/notofonts/latin-greek-cyrillic>
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`

The bundled font provides representative glyph shapes only. Printer profiles
remain authoritative for character cells, baselines, spacing, and
advancement.
